# Password Strength Checker GUI

A Python-based graphical user interface (GUI) application to evaluate the strength of a password. The application provides real-time feedback and color-coded indicators (red for weak, yellow for medium, and green for strong) to help users create secure passwords.

## Features

- **Real-time password strength evaluation** as you type.
- **Color-coded feedback**:
  - **Red** for weak passwords.
  - **Yellow** for medium strength passwords.
  - **Green** for strong passwords.
- Displays **feedback messages** that guide users in creating stronger passwords.
- **Clear Button**: Allows users to reset the input field and feedback area.
- Based on **criteria** like length, special characters, uppercase, lowercase letters, and more.

## Requirements

- Python 3.x
- `tkinter` (comes pre-installed with Python, no installation needed)
